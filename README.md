# 影響力投資與 B 型企業圖鑑 / Impact Investing & B Corps

> 一份雙語、每項事實附來源的圖鑑:影響力投資的概念與歷史、B 型企業運動、尤努斯與窮人銀行、各國案例、關鍵人物,以及台灣的生態系。

緣起是 2026-07-19 一場峰會上,活水影響力投資共同創辦人陳一強(Ray Chen)關於影響力投資的分享(B 型企業、尤努斯的格萊珉銀行等)。這個 repo 是後續的功課:先做成六份附來源的研究筆記([`research/`](research/)),再整理成一個可瀏覽、可搜尋的多頁面靜態網站。全站逾 390 條參考連結。

## ✨ 功能特色

- 🌏 **雙語切換** — English / 中文一鍵切換,整站(含開啟中的詳情視窗)重繪無殘留
- 🌗 **深色 / 淺色模式** — 編輯風雙主題,選擇會被記住
- 📄 **多頁面** — 總覽、核心概念、B 型企業、尤努斯與窮人銀行、各國案例、關鍵人物、台灣生態系,各有獨立網址
- 🔗 **深連結** — 每個案例/人物有專屬 `#<slug>`,可直接分享詳情(內含參考來源)
- 📚 **術語速查** — 可搜尋的影響力投資詞彙表
- ✏️ **隨堂測驗** — 12 題即時對錯回饋 + 解釋(僅存於當前瀏覽,不追蹤個人)
- 🃏 **字卡** — 點擊翻面的詞義複習卡
- 📱 **響應式設計** — 手機、平板、桌機皆適配
- ⚡ **純靜態** — 無後端、零 build、載入快

## 📂 內容結構 / 資料來源

```
impact-investing/
├── index.html          # 總覽(hub)
├── concepts.html …     # 各主題頁(共 10 頁,共用 shell)
├── assets/             # 樣式、共用 chrome(shell.js)、版面引擎(app.js)
├── data/
│   ├── pages/*.js      # 每頁一個資料 fragment(雙語 + 來源連結)
│   └── data.js         # 組裝 SITE_META + SITE_PAGES
└── research/           # 六份完整研究筆記(逐項事實 + 全部來源連結)
```

本站內容整理自 **GIIN、B Lab、格萊珉銀行、諾貝爾委員會等機構的官方網站與報告、學術研究,以及各媒體的公開報導**;每一項事實在 [`research/`](research/) 筆記與網站內文都附上來源連結。筆記中標注「待查證」的內容,網站上不寫成斷言。

## 🛠 本機使用

```bash
# 1. clone 專案
git clone https://github.com/tingwei161803/impact-investing.git
cd impact-investing

# 2a. 最簡單:直接開啟 index.html
open index.html

# 2b. 或啟動本機伺服器(建議,深連結才正常)
uv run python -m http.server 4173
# 然後瀏覽 http://localhost:4173
```
